## One More Thing

Before running this project, you may want to create a superuser.

## Synchronize The Database

This project has default settings for the database (SQLite).
If you need a superuser, create one before running the project.

1. Open Solution Explorer.
2. Right-click the project node and select `Python -> Django Create Superuser`.
3. Enter account details when prompted.

This creates a new account, and the details do not need to match any of your existing accounts.
